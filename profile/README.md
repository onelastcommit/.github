### Projects

**[Cursus](https://getcursus.app)**
A free CV builder, UK-first. Exports a print-ready PDF and a plain, ATS-friendly DOCX, so your CV reads well to humans and parsers alike.
`Next.js` · `NestJS` · `PostgreSQL` · `Prisma`

**[Noctra](https://getnoctra.dev)**
An open-source, self-hosted AI PR runner that lives on a Raspberry Pi. It picks up Linear tickets, works them with the coding agent of your choice, reviews code, and spends spare tokens tidying things up over time. Controlled over Telegram.
`Go` · `Raspberry Pi` · `Linear` · `Telegram`

**[OneNote MCP](https://github.com/onelastcommit/onenote-mcp)**
A Model Context Protocol server for Microsoft OneNote, so AI assistants can read and work with your notebooks.
`TypeScript` · `MCP`

**[Ledger](https://github.com/onelastcommit/ledger)**
An append-only event store on plain PostgreSQL. Every event records who did it and why, and every entity follows its own state machine, so "how did it end up like this?" has an actual answer.
`TypeScript` · `PostgreSQL` · `Event sourcing`

**[Friday](https://github.com/onelastcommit/friday)**
A command-line coding agent with Claude as the only brain in the room. It can ask GPT or Gemini for a second opinion, but only Claude gets to act on it.
`TypeScript` · `Claude` · `MCP`
